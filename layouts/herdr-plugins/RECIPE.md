# Herdr 插件布局

一个面向 macOS 的 Herdr 工作区布局，提供蓝灰色侧栏、清晰的选中状态，以及对话历史、文件树、Git 工作台和插件设置。

![Herdr 插件布局](preview.png)

预览图取自实际界面；终端、空间名称和状态栏中的个人内容已遮盖。

## 看到的界面

左侧是空间和 Agent 列表，底部「设置」行最右侧的图标打开插件开关。顶部显示标签及文件、改动、Git 和历史面板入口；中间是终端工作区，右侧面板用于文件、改动、历史和 Git 工作台。布局使用浅色蓝灰界面、蓝色空间选中态和圆角面板。

## 使用方式

点击侧栏空间或 Agent 切换焦点；右侧面板由顶部按钮打开。插件设置支持启用或关闭对话历史、桌面动效、工作区中文、命令提示和 Git 工作台。标签支持切换、关闭和拖动；工作中的 Agent 显示旋转状态，等待或完成时显示对应状态标识。

历史面板按 CLI 和项目分组，双击恢复原会话，右键可向另一 CLI 交接文本。历史面板中的删除会删除本机会话文件。文件树使用缩进、文件夹字重和图标颜色区分层级。命令提示从底部状态栏展开；Git 工作台可查看本地仓库和 GitHub PR。

## 实现与安装

布局文件为 `layouts/herdr-plugins.json`，复制到 Herdr 的 `layouts/`；`mods/` 中每个目录复制到 Herdr 的 `mods/`。资源引用使用本机 `appHome()`，无需改写用户名。安装前按本机 `~/.config/herdr-app/AGENTS.md` 逐文件审阅，检查所有布局和 Mod 的同名冲突；不得覆盖已有文件。本版本的管理器固定使用布局名 `herdr-plugins`，若名称冲突必须同时适配布局、管理器、元数据和所有 Mod 引用；不能只改布局文件名。

布局依赖 Herdr 0.1.10 的官方 `main`、`tabs`、`files`、`changes`、`workspace-chrome` 等模块及图标。复制后对每个 Mod 执行 `herdr-app check`，切换 `herdr-plugins` 并检查 `herdr-app status`。设置面板的后端按需创建布局组合元数据，生成组件以内容摘要命名，不修改官方 Mod。

布局和 Mod 会运行本地 Python、Git、CLI 和 `gh`；历史模块读取、恢复及删除本机会话文件，并可将历史文本传给目标 CLI；Git 工作台可通过 `gh` 访问 GitHub。程序依赖 macOS 的 `/usr/bin/python3` 和 `/bin/zsh`，恢复对话及 PR 功能需本机安装对应 CLI 和 `gh`。工作区中文只覆盖布局中的 Mod，不修改 Herdr 设置页等 frame，也不安装 LaunchAgent。

## 注意

这份构建包含浅色配色，暗色外观尚未适配。Herdr 升级后官方模块源码结构变化可能导致插件开关拒绝组合，此时应按当前版本的官方指南适配，不能覆盖官方模块。首次复制时若已有旧版 `plugin-controls` 元数据，应先检查冲突，不能覆盖或直接复用。`herdr-app check` 只能验证初始加载，不能代替实际操作验证。

## 完成标准

布局和全部 Mod 通过 `herdr-app check`，切换后状态无错误；在干净环境中逐项关闭和重新开启五项功能，确认其他面板仍正常。检查历史恢复与 Git 功能时使用可公开的测试数据。
