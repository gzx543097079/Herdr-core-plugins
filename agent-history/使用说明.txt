Herdr 桌面端本地对话历史

通过仓库根目录 README.md 中的 Herdr 官方布局安装方式安装。安装后在顶部打开对话历史，可搜索本机 Codex 和 Claude Code 的标题或项目路径；标题优先使用对话自身的名称（Claude 的重命名或自动标题），没有时才取第一条真实提问。双击记录，在对应项目的新标签页中恢复会话。

右键记录可 Fork：同 CLI 会创建分支对话（Claude 使用 --fork-session，Codex 使用 fork），跨 CLI 则把历史文本交给目标 CLI；Fork 会新建一个空间，因此侧栏「空间」中会出现对应项目。

需要本机安装对应的 codex 或 claude 命令。仅搜索本机默认目录中的会话，不上传对话数据。

可通过左下角设置行右侧的插件设置图标启用或关闭对话历史。关闭功能不会删除历史记录；在历史面板中明确删除记录会删除相应的本地文件。
